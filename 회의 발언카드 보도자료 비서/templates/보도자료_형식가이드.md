# 경기도의회 보도자료 작성 형식 가이드

경기도의회 홈페이지 보도자료 게시판 최신 글 분석 기반.
출처: https://www.ggc.go.kr/site/main/xb/lwmkr/lawmakerpressrelease

---

## 문체 학습 우선순위 (중요)

1. **해당 의원의 기존 보도자료**가 게시판에 있으면 → 그 의원의 문체·표현·즐겨 쓰는 어휘를 참고
2. 없으면 → **최근 보도자료 약 10건**의 공통 형식을 참고

---

## 표준 구조

### 1. 제목
형식: `○○○ 의원, [주제 + 핵심 주장]`
- 의원명 + 쉼표 + 주제/주장
- 핵심 쟁점은 작은따옴표로 강조 가능
- 예) `이인애 의원, 신원고 학급 증설 및 고교 근거리 배정 대책 마련 촉구`
- 예) `성복임 의원, 매년 반복되는 결산 문제, 개선으로 이어져야`

### 2. 리드문 (첫 문단 · 한 문장으로 압축)
공식:
> 경기도의회 **[상임위원회]** ○○○ 의원(**[정당], [지역구]**)은 **[날짜]일** [회의/장소]에서 [무엇을 하며] [핵심 주장]을 **[촉구/강조/당부]했다.**

- 예) 경기도의회 여성가족평생교육위원회 이인애 의원(국민의힘, 고양2)은 16일 … 「신원고 학급 증설 관련 간담회」를 개최하고, … 개선 대책 마련을 촉구했다.
- 예) 경기도의회 건설교통위원회 성복임 도의원(더불어민주당, 군포4)이 16일 열린 제391회 정례회 … 결산심사에서 … 점검해야 한다고 강조했다.

### 3. 본문 (발언 인용)
- 의원 발언을 **직접 인용("…")** + 서술동사로 연결
- 첫 등장은 "○○○ 의원은", 이후는 "○ 의원은"(성 + 의원)
- 서술동사: 강조했다 / 밝혔다 / 말했다 / 지적했다 / 당부했다 / 제안했다 / 촉구했다
- 직접 인용구를 문단별로 순차 배치 (한 문단 = 한 논점)
- 예) 이 의원은 "고등학교 배정은 단순히 학교를 배정하는 행정절차가 아니라 학생들의 교육권과 생활권, 통학 안전과 직결된 문제이다"라고 강조했다.

### 4. 맺음 문단
- 행사 참석자 명단, 또는 향후 계획·당부로 마무리

### 5. 길이
- 7~12문단 (리드 1 + 본문 인용 6~10)

## 작성에 필요한 정보
| 구분 | 항목 | 비고 |
|------|------|------|
| 필수 | 의원 이름, 소속 상임위원회 | 요청 시 입력 |
| 필수 | 발언 내용 | 영상 음성 추출 또는 현장 메모 |
| 권장 | 정당, 지역구 | 리드문에 사용. 의원 이름으로 자동 조회 가능 |
| 자동 | 날짜, 회기/안건 | 배포일·회의 정보로 채움 |
